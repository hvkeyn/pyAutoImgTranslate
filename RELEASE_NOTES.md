# pyAutoImgTranslate — Release Notes

## v1.6.0

Кросс-платформенность: релиз для Windows и Linux (Debian), исправления, найденные
на реальном запуске под Debian.

### Добавлено

- **.deb-пакет для Debian/Ubuntu.** `build_deb.sh` собирает устанавливаемый пакет
  `pyautoimgtranslate_<version>_<arch>.deb`: бинарник в `/usr/lib`, лончер в
  `/usr/bin/pyautoimgtranslate`, пункт меню и иконка, зависимости в `Depends`,
  хуки `postinst`/`prerm`. Устанавливается через `apt install ./….deb`.
- **Поддержка Linux (Debian/Ubuntu).** Автодетект ОС: горячие клавиши `Ctrl+Alt+S` /
  `Ctrl+Alt+A`, буфер обмена через `xclip`/`xsel`/`wl-paste`, захват области через
  `grim`/`gnome-screenshot`/`spectacle`/`scrot`/`maim`/`flameshot`, автозапуск
  через `~/.config/autostart/*.desktop`, глобальные хоткеи через `pynput`,
  единый экземпляр через файловую блокировку.
- **Скрипты сборки:** `build.sh` (Linux) и `build.bat` (Windows).
- **Релизы:** `pyAutoImgTranslate.exe` (Windows), `pyAutoImgTranslate` (Linux) и
  `pyautoimgtranslate_<version>_amd64.deb` (Debian/Ubuntu).

### Исправлено (найдено при тестировании под Debian)

- **Не-ASCII API-ключ ломал HTTP-заголовки** (`latin-1`) — теперь ключ проверяется,
  а плейсхолдер по умолчанию сделан ASCII, с понятной ошибкой.
- **Краш трея на X11** из-за кириллицы в title иконки — имя сделано ASCII.

### Возможности (с v1.5.0)

Исправлен захват Win+Shift+S, добавлено окно прогресса, единое окно настроек и баланс API.

### Исправлено

- **Win+Shift+S ничего не показывал.** Раньше после нажатия программа ждала кликов
  мышью (клик уже был сделан в оверлее Windows) и отменялась при любом нажатии клавиши.
  Теперь программа запоминает номер буфера обмена и ждёт в нём **новую** картинку —
  результат выделения. Работает и через любой другой способ скриншота.

### Добавлено

- **Мини-окно прогресса.** Компактная плашка с «песочными часами», этапом,
  **плавно растущим процентом** (0→100%), полосой прогресса и **оценкой остатка
  времени** (ETA: «прошло 5 с · осталось ~3 с»). По центру внизу, не перекрывает
  выделение.
- **Единое окно настроек.** Повторный вызов из трея или окна результата поднимает
  уже открытое окно, а не создаёт второе.
- **Баланс API.** В окне настроек показывается баланс нейросети (DeepSeek) с кнопкой
  обновления; для локальных серверов — «не применимо».

### Возможности (с v1.4.0)

Свободный выбор модели с предупреждением о vision + единая дизайн-система для интерфейса.

### Добавлено в этой версии

- **Свободный выбор модели.** Можно выбрать любую модель; если у неё нет поддержки
  изображений, в окне настроек показывается **предупреждение** (не запрет).
- **Подсказка про vision.** В режиме «Нейросеть» под выбором модели появляется строка
  «⚠ Модель … может не поддерживать изображения» с советом выбрать vision-модель
  (например, `deepseek-flash`) или переключиться на Tesseract.
- **Дизайн-система.** Введены токены (цветовые роли, шкала отступов 4/8, типографика,
  варианты кнопок) и переиспользуемые компоненты — кнопки, поля, сегментированный
  переключатель. Все окна (результат, настройки) построены только на токенах.
- **Переработанное окно результата:** заголовок с источником («Перевод · нейросеть»),
  карточка текста, сегментированный переключатель **Перевод / Оригинал**, панель действий.

### Возможности (с v1.3.0)

Перевод целиком через нейросеть: по умолчанию модель **сама читает картинку** (vision).

### Добавлено в этой версии

- **Vision-перевод по умолчанию.** Нейросеть получает изображение и сразу возвращает
  перевод близко к оригиналу — без Tesseract. На тесте синтетической картинки Tesseract
  ошибался, а vision-модель прочитала текст точно.
- **Выбор режима распознавания** в настройках: «Нейросеть (vision, точнее)» или
  «Tesseract (локально)» (`ocr_mode`: `ai` / `tesseract`).
- **Актуальные модели DeepSeek:** `deepseek-flash` (по умолчанию), `deepseek-v4-pro`,
  а также legacy `deepseek-chat` / `deepseek-reasoner`.
- Перевод текста и перевод картинки теперь идут через общий нейросетевой вызов
  (`/chat/completions`).

### Совместимость моделей (vision)

- ✅ `deepseek-flash` и `deepseek-chat` — принимают изображения.
- ✅ LM Studio с vision-моделью (например, Qwen2.5-VL, LLaVA) — принимает изображения.
- ⛔ `deepseek-v4-pro` — без vision, только текст (для картинок используйте `deepseek-flash`).

### Возможности (с v1.2.0)

Живое распознавание («на лету»), перевод близко к оригиналу, копирование и
автонастройка Tesseract.

### Добавлено в этой версии

- **Режим «на лету».** Трей → «Режим «на лету»» или `Win+Shift+A`: как только в буфере
  обмена появляется новая картинка (например, после Win+Shift+S), текст сразу
  распознаётся и переводится — без дополнительного нажатия.
- **Перевод близко к оригиналу.** Промпт переписан на точный/дословный перевод с
  сохранением структуры (строки, абзацы, списки, числа, имена).
- **Копирование и сравнение.** В окне результата — переключатель «Оригинал / Перевод»
  (`Ctrl+O`) и копирование текущего текста (`Ctrl+C`, кнопка, контекстное меню).
- **Автонастройка Tesseract.** `TESSDATA_PREFIX` определяется автоматически — OCR
  работает, даже если `tessdata` не в PATH (частая проблема «Failed loading language»).

### Возможности (с v1.1.0)

- **Полностью редактируемый каталог провайдеров.** Провайдеры лежат списком в
  `config.json` (`providers[]`) и добавляются/удаляются/переименовываются в окне настроек.
- **Модели на лету.** У каждого провайдера свой список моделей; кнопки `+` / `−`
  добавляют и удаляют модели.
- **Переподключение без перезапуска.** «Сохранить» применяет конфиг к работающему
  приложению мгновенно.
- **Перезагрузить из файла / Проверить / Миграция старого конфига.**

### Возможности (с v1.0.0)

- **Скриншот и перевод:** Win+Shift+S → выделение области → OCR (Tesseract,
  выравнивание наклона OpenCV) → ИИ-перевод → окно результата.
- **Автозапуск с Windows** (трей / окно настроек, реестр `HKCU\...\CurrentVersion\Run`).
- **Трей и логи,** защита от второго экземпляра, ротируемый лог.

### Проверено

- Запуск из исходников и из `main.exe`: хоткей и режим «на лету» регистрируются, трей поднимается.
- Режим «на лету»: новая картинка в буфере → автоматический OCR+перевод.
- E2E на синтетическом скриншоте: OCR → близкий к оригиналу перевод.
- Окно результата: переключатель «Оригинал / Перевод» и копирование.
- Миграция старого `config.json`; live-переключение провайдера/модели.
- Реальный запрос к DeepSeek: `Hello, world!` → `Привет, мир!`.

### Сборка

```
pyinstaller --noconfirm --clean main.spec
```

Результат — `dist/main.exe` (one-file).

### Важно

- API-ключ DeepSeek по умолчанию задан в `main.py`. Для публикации замените его
  на плейсхолдер и задавайте ключ через `config.json` или переменную окружения
  `DEEPSEEK_API_KEY`. Не коммитьте `config.json` с реальным ключом (он в `.gitignore`).
- Требуется установленный Tesseract OCR (путь настраивается в `config.json` /
  окне настроек; `TESSDATA_PREFIX` определяется автоматически).
